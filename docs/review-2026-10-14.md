## Fixes on the consolidated working branch

- Incorporate PR #35's per-guild reconnect guard and grace period: concurrent
  callers share one task; a recovered Discord client is adopted, not replaced.
- Correct a bug in that PR: public `VoiceClient.disconnect()` does not accept
  `wait=True` in discord.py 2.7.1. The old blanket exception suppression hid
  the resulting TypeError. Use `force=True`; the library waits internally.
- Cancel and join the old websocket runner and connector before replacement.
  A grace-period timeout alone does not mean Discord's task has stopped.
  Failed teardown now prevents a competing connect rather than being swallowed.
- Preserve cancellation isolation for callers waiting on the shared reconnect.
- Recover silent guilds independently: a playing guild no longer prevents a
  different occupied guild from recovering. Count disconnected time when sampled;
  clear gates on empty/admin pause; report failure if every player start fails.
- Integrate `main`'s known-duration EOF advance, resetting both the shared clock
  and persisted cursor, including one-track wraps. Within a track, keep the
  cursor; if the provider changes the track, fan it out to connected listeners.
- Keep production's flap detector, unknown-duration warnings, 10-second health
  threshold, and 5-second heartbeat unchanged.

### Deliberately not copied from main

Its “8 seconds silent means restart at zero” fallback did not prove an offset
restart had failed, and did not reset the authoritative clock. Blindly copying
it would reintroduce repeated rewinds/desynchronized audio. That code and its
incident history are preserved in the archive tag, not silently discarded.
Metadata and cache fixes below are still needed for unknown-duration media.
